 ## Evaluation Report: Model Prediction and Feature Importance

## 1. Introduction

This report evaluates and interprets a Random Forest classification model trained on the Breast Cancer Wisconsin dataset. The objective is not only to measure how accurately the model classifies unseen samples, but also to understand which features influence its predictions.

The evaluation combines traditional classification metrics with model-interpretation techniques using SHAP (SHapley Additive exPlanations).

---

## 2. Dataset and Model

The Breast Cancer Wisconsin dataset contains 569 observations and 30 numerical features describing characteristics of cell nuclei.

The target variable contains two classes:

- Malignant
- Benign

The dataset was divided into training and testing sets using an 80:20 split. Stratified sampling was used to maintain a similar class distribution in both sets.

A Random Forest Classifier with 200 decision trees was trained on the training data.

RandomForestClassifier(
    n_estimators=200,
    random_state=42
)

---

## 3. Evaluation Methodology

The trained model was evaluated on the unseen test dataset using:

- Accuracy
- Precision
- Recall
- F1-score
- Classification Report
- Confusion Matrix
- ROC Curve
- ROC-AUC

SHAP was then used to interpret the model's predictions and identify the most influential features.

---

## 4. Model Performance Evaluation

4.1 Accuracy

Accuracy measures the percentage of test samples correctly classified by the model.

The exact accuracy should be taken from the output generated by the notebook rather than being manually entered into this report.

A high accuracy indicates that the Random Forest model correctly classifies most of the unseen test samples.

---

4.2 Precision

Precision measures the proportion of positive predictions that are actually positive.

A high precision value indicates that the model produces relatively few false-positive predictions.

This is particularly useful when incorrect positive classifications need to be minimized.

---

4.3 Recall

Recall measures the proportion of actual positive cases that are correctly identified.

A high recall indicates that the model successfully detects most samples belonging to the positive class.

Recall is especially important in classification problems where missing a positive case can be more significant than incorrectly identifying a negative case.

---

4.4 F1-Score

The F1-score combines precision and recall into a single metric.

A high F1-score indicates that the model achieves a good balance between identifying positive cases and avoiding incorrect positive predictions.

The actual precision, recall, and F1-score values should be copied from the notebook's "classification_report()" output.

## 7. SHAP-Based Model Interpretation

7.1 Why SHAP Was Used

Traditional evaluation metrics tell us how well the model performs, but they do not explain why the model makes a particular prediction.

SHAP addresses this problem by estimating the contribution of individual features to model predictions.

A SHAP TreeExplainer was used because the model is a tree-based Random Forest classifier.

---

## 8. SHAP Summary Plot Interpretation

The SHAP Summary Plot provides a global interpretation of the model.

It ranks features according to their overall contribution to the model's predictions.

The plot is available at:

"assets/shap_summary.png"

Features appearing near the top of the plot have a greater overall influence on predictions, while features near the bottom have comparatively less influence.

The horizontal position of a SHAP value indicates whether a feature pushes the model's prediction toward one class or the other.

The color represents the feature value:

- Higher feature values are generally shown in red.
- Lower feature values are generally shown in blue.

Therefore, the summary plot can be used to determine both feature importance and the direction of influence.

## 10. Local Prediction Interpretation

The SHAP Force Plot provides a local explanation for an individual prediction.

The interactive visualization is saved as:

"assets/shap_force.html"

Unlike the SHAP Summary Plot, which explains the model globally, the Force Plot focuses on a single test sample.

It shows how individual feature contributions move the prediction toward one class or the other.

This makes it possible to understand why the model classified a particular sample in a specific way.

---

## 11. Global vs Local Interpretation

The project provides two levels of interpretability.

Global Interpretation

The SHAP Summary Plot and SHAP Feature Importance Plot explain:

«Which features are most important to the model overall?»

Local Interpretation

The SHAP Force Plot explains:

«Which features influenced this particular prediction?»

Combining both perspectives provides a more complete understanding of the Random Forest model.

## 12. Key Findings

Based on the evaluation methodology:

1. The Random Forest model provides strong classification performance on the test dataset.
2. Precision, recall, and F1-score provide a more detailed evaluation than accuracy alone.
3. The confusion matrix helps identify the number of correct and incorrect classifications for each class.
4. The ROC curve evaluates classification performance across different decision thresholds.
5. ROC-AUC provides a threshold-independent measure of the model's ability to separate the two classes.
6. SHAP reveals which input features have the greatest influence on the model.
7. The SHAP Summary Plot provides a global explanation of model behavior.
8. The SHAP Force Plot provides an explanation for an individual prediction.

---

## 13. Conclusion

The evaluation demonstrates that model assessment should involve both performance evaluation and interpretability.

The Random Forest model can be evaluated quantitatively using accuracy, precision, recall, F1-score, confusion matrix, and ROC-AUC. However, these metrics alone do not explain the reasoning behind individual predictions.

SHAP provides this additional layer of interpretation by showing how individual features contribute to predictions. The combination of global SHAP analysis and local force-plot analysis makes the model's behavior easier to understand and provides greater transparency into its decision-making process.
